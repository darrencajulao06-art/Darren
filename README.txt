AGRISHOP - FINAL PROJECT
Static E-Commerce Website using Frontend Technologies

CONTENTS
- index.html : login page and all customer/seller interface sections
- style.css  : responsive green agricultural theme and layout
- script.js  : login validation, navigation, shopping cart, wishlist, checkout simulation,
               order history, and seller product management

HOW TO RUN
1. Extract the ZIP file to a folder.
2. Open index.html in a modern browser (Chrome, Edge, or Firefox).
3. No database, server, or installation is required. Internet is only used for the optional Google Fonts import;
   the website layout and emoji product illustrations work without external image assets.

FEATURES
Customer:
- Role-based login validation
- Home page with welcome banner, highlights, and featured products
- Product catalog with search and category filter
- 4 product categories
- Add to cart, change quantity, remove items, and simulated checkout
- Wishlist save/remove actions
- Sample and locally created order history
- Profile and settings
- Responsive side navigation and logout

Seller:
- Dashboard with product count, sample order count, and sales summary
- Product inventory table
- Add, edit, search, and delete products
- Sample orders and seller profile
- Product changes persist in browser localStorage

NOTES
- This is a frontend-only educational demo. It does not use a database or real authentication/payment.
- Data is saved in the browser's localStorage. If browser storage is cleared, saved changes may be lost.
- Use the browser's responsive design/devices mode to check desktop, tablet, and mobile layouts.
- Suggested screenshots for the project report: login page, customer home desktop, products/cart, seller dashboard,
